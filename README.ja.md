# Fit

**macOS のウィンドウをキーボードでスナップするツール。** [Magnet](https://apps.apple.com/jp/app/magnet/id441258766) の代替 OSS で、Xcode さえあれば自分でビルドして使えます。会社支給の Mac など、App Store からアプリを入れられない環境を想定しています。

[English README is here](README.md)

## なぜ Fit か

会社の Mac だと、App Store からのインストールが制限されていることがよくあります。でも Xcode は入っている——そんな環境向けに作りました。

- **Xcode だけでビルドできる。** リポジトリを clone して Fit.xcodeproj を開き、⌘R。Apple ID も Developer Program も署名証明書も要りません。
- **外部依存なし。** Swift Package の解決も CocoaPods もありません。clone してしまえばオフラインのままビルドできます。
- **ネットワークコードなし。** テレメトリも自動アップデートも入っていません。要求する権限はアクセシビリティのみ。全体で 2,000 行程度の Swift なので、セキュリティレビューも簡単です。

## 機能

- 前面のウィンドウをキーボードショートカットでスナップ（デフォルトは Magnet 互換）：
  左右／上下半分、4 分の 1、3 分の 1、3 分の 2、最大化、中央寄せ、元のサイズに戻す
- 半分のショートカットを連打するとサイズが ½ → ⅔ → ⅓ とサイクル（左右・上下いずれも）
- 半分にスナップした後、直角に交わる半分のショートカットで角へジャンプ：⌃⌥ ← のあと ⌃⌥ ↑ で左上 4 分の 1
- ウィンドウを画面の端や角にドラッグしてスナップ（プレビュー付き）
- ⇧ を押している間はエッジスナップを一時停止（修飾キーは変更可）
- 隣のディスプレイへウィンドウを移動
- マルチディスプレイ対応。Dock やメニューバーの領域は自動で避けます
- スナップしたウィンドウ同士の隙間（ギャップ）を調整可能
- ショートカットはアプリ内で自由に変更可能
- メニューバー常駐、Dock にアイコンは出しません
- ログイン時の自動起動に対応

## デフォルトショートカット

| 操作 | ショートカット |
|---|---|
| 左半分 / 右半分 | ⌃⌥ ← / ⌃⌥ → |
| 上半分 / 下半分 | ⌃⌥ ↑ / ⌃⌥ ↓ |
| 4 分の 1（左上／右上／左下／右下） | ⌃⌥ U / I / J / K |
| 3 分の 1（左／中央／右） | ⌃⌥ D / F / G |
| 3 分の 2（左／右） | ⌃⌥ E / T |
| 最大化 | ⌃⌥ Return |
| 中央寄せ | ⌃⌥ C |
| 元のサイズに戻す | ⌃⌥ Delete |
| 前 / 次のディスプレイへ | ⌃⌥⌘ ← / ⌃⌥⌘ → |

すべて **Settings → Shortcuts** から変更できます。

⌃⌥ ←（→、↑、↓ でも同じ）を連打すると、その方向にサイズが ½ → ⅔ → ⅓ とサイクルします。手でウィンドウを動かしたり、別のスナップを実行するとリセットされます。

半分のショートカットを 2 つ続けて押すと角にジャンプします。⌃⌥ ← のあと ⌃⌥ ↑ で左上、⌃⌥ → のあと ⌃⌥ ↓ で右下——といった具合に、8 通りの組み合わせで四隅すべてに届きます。1 回目のショートカットで置いた位置にウィンドウが残っていることが発火条件なので、矢印キーだけで 4 つの半分と 4 つの角すべてに手が届きます。

どちらの挙動も Settings で個別にオフにできます。

## ドラッグスナップのゾーン

ドラッグしていって、ポインタが画面の端に触れたところで離すとそこにスナップします：

```
┌────┬─────────── 最大化 ─────────────┬────┐
│ 左上│                               │ 右上│
├────┤                                ├────┤
│    │                                │    │
│ 左半│                               │ 右半│
│    │                                │    │
├────┤                                ├────┤
│ 左下│                               │ 右下│
└────┴── 左⅓ ──── 中央⅓ ──── 右⅓ ────┴────┘
```

- 左右の端 → 半分。端の上下 1/4 あたりにポインタがあれば角の 1/4
- 上端 → 最大化
- 下端 → 3 分の 1

## ビルドとインストール

要件: **macOS 13 Ventura 以降、Xcode 16 以降**

```sh
git clone https://github.com/EitaroY/fit.git
cd fit
./scripts/install.sh
```

インストールスクリプトが以下を一気に片付けます：自己署名の code-signing 証明書を作成（初回のみキーチェーンパスワードを聞かれます）→ Release ビルド → その証明書で署名 → `/Applications` へインストール → 起動。以後は再ビルドしても署名が変わらないので、`git pull && ./scripts/install.sh` を繰り返してもアクセシビリティ許可は外れません。

初回起動時に**アクセシビリティ**の権限を要求されます（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。他アプリのウィンドウを動かすアプリすべてに求められる、macOS 標準の権限です。

Xcode を直接開いて **⌘R** でも動きます。ただしアドホック署名になるため、再ビルドするたびにアクセシビリティ許可を付け直すことになります。詳細は [docs/BUILDING.md](docs/BUILDING.md) を参照してください。

## トラブルシューティング

- **再ビルドしたらショートカットが効かなくなった。** Xcode の ⌘R（アドホック署名）でビルドしたのが原因です。`./scripts/install.sh` を使えば署名が安定するので、以後は再ビルドしても許可が維持されます。とりあえず直したいなら、アクセシビリティ一覧から Fit を削除（−）して入れ直してください。
- **ウィンドウがぴったりリサイズされない。** 最小サイズやグリッド単位のリサイズ制約を持つアプリ（ターミナルなど）があります。Fit はそのアプリが許す範囲で一番近いサイズに合わせます。
- **ネイティブフルスクリーン**（緑ボタンで入るフルスクリーン）中のウィンドウはスナップできません。フルスクリーンを解除してから操作してください。

## プロジェクト構成

```
Fit/                 アプリ本体
  App/               エントリポイント、AppDelegate、ステータスバー
  Core/              純粋ロジック: スナップ座標計算、ドラッグゾーン判定（AppKit 非依存・ユニットテスト対象）
  Windowing/         アクセシビリティ API ラッパー、スクリーン座標変換
  Input/             グローバルホットキー（Carbon）、ドラッグスナップ監視
  UI/                設定ウィンドウ、オンボーディング、スナッププレビュー
  Support/           設定ストア、ログイン項目
Tests/FitCoreTests/  コアロジックのユニットテスト（`swift test`）
docs/DESIGN.ja.md    詳細設計書
```

コアロジックのテストは Xcode を開かなくても実行できます：

```sh
swift test
```
